# Project Notes

This repository contains the KONGER / 空二 portfolio prototype.

Use `src/assets/konger` for the frontend-ready optimized WebP images. The larger local source archive is kept outside the GitHub source tree in `source-assets/konger-works/Art`.

Before major visual changes, keep the current direction: quiet curation wall, real artwork first, restrained typography, responsive desktop/mobile presentation, and click-through modals for full artwork viewing.

Run `npm run build` before publishing changes.
