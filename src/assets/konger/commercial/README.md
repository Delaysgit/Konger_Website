# 前端商业作品资源

这里存放压缩后的前端可用商业作品封面和预览图。

不要把大体积原始素材放这里。原始素材请放到：

`source-assets/konger-works/commercial`

前端资源建议命名：

- `client-project-cover.webp`
- `client-project-preview-01.webp`
- `client-project-preview-02.webp`

- `tencent-medipedia-arsenic-history-cover.webp`
- `baidu-medipedia-project-name-cover.webp`
- `simmons-project-name-cover.webp`
- `shanhun-series-name-cover.webp`
