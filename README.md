# Lin Youhe Portfolio

A clean, gallery-style illustrator portfolio prototype for the fictional artist Lin Youhe.

The direction is based on the selected **Quiet Curation Wall** concept: restrained whitespace, quiet typography, a unified artwork grid, and stronger project personality inside individual work detail views.

## Features

- Responsive illustrator portfolio homepage
- Quiet editorial hero section
- Featured work carousel controls
- Category filters for the work grid
- Clickable project detail modal
- Mobile navigation menu
- Generated WebP artwork assets
- Product Design QA report in `design-qa.md`

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Project Notes

The source lives in `src/`.

Generated artwork assets are stored in `src/assets/`.

QA screenshots and comparison evidence are stored in `qa-shots/`.
